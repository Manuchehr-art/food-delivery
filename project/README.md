# Информационная система «Болаззат» — Доставка еды (Food Delivery)

Веб-приложение для автоматизации процессов заказа, обработки и доставки еды в городе Душанбе. Разработано на чистом **PHP** с использованием классической архитектуры **MVC (Model-View-Controller)** и реляционной базы данных **MySQL** с возможностью управления через **phpMyAdmin**.

---

## 🌟 Основные возможности

### 1. Клиентская часть (Портал муштарӣ):
- **Каталог ресторанов и меню:** фильтрация по категориям (*Пицца, Бургеры и горячее, Салаты, Напитки, Десерты*), быстрый поиск блюд.
- **Интерактивная корзина:** проверка минимальной суммы заказа для каждого ресторана, автоматический расчёт стоимости доставки.
- **Оформление заказа:** сохранение адресов доставки в Душанбе, поддержка местных способов оплаты:
  - 💵 **Наличные (Нақд)** — курьеру при передаче заказа;
  - 📱 **Alif Mobi** — быстрая оплата по QR-коду;
  - 💳 **Dushanbe City (DC)** — кошелёк и карты DC;
  - 🌐 **Банковские карты (Корти миллӣ / Visa / MasterCard)**.
- **Отслеживание заказа (Real-time Tracking):** визуальный интерактивный трекер статуса заказа:
  `new (Новый)` ➔ `accepted (Принят)` ➔ `cooking (Готовится)` ➔ `on_the_way (В пути)` ➔ `delivered (Доставлен)`.
- **Система отзывов и оценок:** возможность поставить оценку от 1 до 5 звёзд и оставить комментарий после получения заказа.

### 2. Панель администратора и менеджера (Admin Panel):
- **Аналитика и дашборд:** общая выручка (TJS), количество заказов, заказы в работе, распределение по статусам (GROUP BY status), топ-5 популярных блюд по продажам.
- **Управление заказами:** просмотр всех заказов, фильтрация по статусам и заведениям, оперативная смена статуса, назначение свободных курьеров (`is_busy = 0`).
- **Управление заведениями (Рестораны):** добавление, редактирование, просмотр адресов, телефонов, часов работы, минимального чека и радиуса доставки.
- **Управление меню и блюдами:** добавление блюд с ценами и категориями, **быстрое переключение доступности (is_available)** в 1 клик для отправки в «стоп-лист», если закончились продукты.
- **Управление курьерами:** учет курьеров, тип транспорта (*авто, велосипед/скутер, пеший*), переключение занятости.
- **Отзывы и Пользователи:** просмотр оценок клиентов, реестр пользователей и ролей.

### 3. Мобильный кабинет курьера:
- Адаптированный интерфейс для смартфонов курьеров на линии.
- Просмотр назначенных заказов с контактами ресторана и клиента, быстрый вызов по телефону.
- Быстрые кнопки статусов: *«Забрал заказ (В пути)»* и *«Доставлен (Оплата получена)»*.
- Переключение статуса занятости курьера на смене (*Свободен / На заказе*).

## 🗄️ База данных (MySQL / phpMyAdmin)

Схема нормализована до **3-й нормальной формы (3НФ)** и состоит из 10 связанных таблиц:
1. `users` — учетные записи (роли: `admin`, `manager`, `courier`, `client`);
2. `clients` — карточки клиентов (ФИО, основной телефон, email);
3. `client_phones` — дополнительные телефоны (1НФ);
4. `addresses` — адреса доставки с координатами и комментариями;
5. `restaurants` — заведения-партнёры (минимальный заказ, радиус доставки);
6. `dishes` — блюда ресторанов (цена, категория, флаг `is_available`);
7. `couriers` — курьеры (тип транспорта, статус `is_busy`);
8. `orders` — заказы (статусы, способы оплаты, временные метки);
9. `order_items` — позиции заказов (M:N связь заказов и блюд с исторической фиксацией цены);
10. `reviews` — отзывы с оценкой от 1 до 5 звёзд.

### Импорт в phpMyAdmin:
1. Откройте **phpMyAdmin** в браузере (`http://localhost/phpmyadmin/`);
2. Перейдите во вкладку **«Импорт»** (Import);
3. Выберите файл `database/food_delivery.sql` из папки проекта;
4. Нажмите кнопку **«Импортировать»** (Вперед / Go);
5. База данных `food_delivery` со всеми 10 таблицами и готовыми данными будет создана автоматически!

> **Примечание:** Если MySQL временно не запущен, проект автоматически использует встроенный резервный драйвер SQLite с точно такой же схемой и данными, что позволяет моментально оценить сайт даже без настройки сервера баз данных.

## 🚀 Как запустить сайт

### Способ 1: Быстрый запуск через `run.bat` (Рекомендуется на Windows)
Просто дважды кликните по файлу **`run.bat`** в корне проекта:
- Автоматически запустится локальный PHP-сервер;
- В браузере сразу откроется сайт: `http://localhost:8000`.

### Способ 2: Через командную строку (PHP Built-in Server)
```bash
php -c php.ini -S localhost:8000 -t public
```
Затем откройте в браузере: `http://localhost:8000`.

### Способ 3: Через OpenServer / XAMPP / WampServer
1. Скопируйте папку `sik3site` в папку `htdocs` (или `domains` в OpenServer);
2. Импортируйте `database/food_delivery.sql` в phpMyAdmin;
3. При необходимости отредактируйте параметры подключения в `config/database.php` (по умолчанию: host `127.0.0.1`, user `root`, pass пустой);
4. Откройте `http://localhost/sik3site/public/` (или `http://sik3site.local`).
